# 钢球控制上层

本目录是 STM32F103C8T6、WHEELTEC D36A、MS42CG 步进电机和
MaixCAM2 组成的钢球位置控制工程，不依赖仓库根目录的 H 题小车工程。

## 当前版本：中心 → +5 cm → -5 cm

- D36A 通道 A：`PA5=EN1`、`PA6=ST1/TIM3_CH1`、`PA7=DIR1`。
- 按键：`PB12=K1`、`PB13=K2`、`PB14=K3`，低电平按下。
- OLED：软件 I2C，`PB8=SCL`、`PB9=SDA`，地址 `0x3C`。
- MaixCAM2：`A21/UART4_TX -> PA10/USART1_RX`，115200 8N1，
  二进制协议版本 2，带 CRC16-CCITT。
- TIM3 产生非阻塞 STEP，TIM2 每 1 ms 做速度/加速度规划。
- 开环命令位置软限位为 `±100 STEP`，上电机械中心作为软件零点。
- K3 使能/失能；K1 启动/中止任务；K2 停止任务并让水管目标回软件零位。
- 连续 3 帧有效且完成五点标定的视觉数据后，状态机先控制到
  `position=700 (+5 cm)`，稳定 100 ms 后切换到
  `position=300 (-5 cm)`，稳定 300 ms 后保持。
- 控制器采用参考 X42S 工程的原始串级 PID 参数：位置外环输出目标球速，
  速度内环输出水管命令位置。
- 实物首次测试发现 -5 cm 附近存在稳态偏差，外环 Ki 已从 `0.050`
  单独提高到 `0.100`；其他增益保持不变，便于对照验证。
- 已按实测方向配置：正 STEP 使 MaixCAM2 坐标增大，PID 输出不取反。
- 接受 MaixCAM2 的 `TRACK_HELD` 帧：短暂漏检时沿用最后坐标参与控制，
  位置保持不变时速度估计会回到 0；串口连续失联 500 ms、坐标无效或
  任务超过 8 s 时进入 `FAULT`。
- PID 水管命令限制为 `±60 STEP`，底层绝对软件围栏仍为 `±100 STEP`。

OLED 中 `B/T` 是小球当前/目标归一化坐标，`M/P` 是 PID 水管目标和已经
实际输出完成的命令脉冲位置。`R/E` 是通过协议校验的接收帧数和
CRC/协议错误数。`B` 直接显示最近一次成功解析的 0～1000 坐标，不再被
上层PID状态筛选隐藏。

## 目录

- `stm32f103c8t6/`：Keil MDK-ARM 工程和 STM32 标准外设库源码。
- `maixcam2/main.py`：MaixCAM2 视觉检测、五点标定和 UART 发送程序。

## 安全说明

系统没有机械原点或限位开关，命令位置不等于编码器反馈。每次上电必须先
将水管放在机械中心；改变软限位、最大速度或加速度前需确认机械行程安全。
