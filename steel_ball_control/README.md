# 钢球控制上层

本目录是 STM32F103C8T6、WHEELTEC D36A、MS42CG 步进电机和
MaixCAM2 组成的钢球位置控制工程，不依赖仓库根目录的 H 题小车工程。

## 当前基线：定时器非阻塞运动测试

- D36A 通道 A：`PA5=EN1`、`PA6=ST1/TIM3_CH1`、`PA7=DIR1`。
- 按键：`PB12=K1`、`PB13=K2`、`PB14=K3`，低电平按下。
- OLED：软件 I2C，`PB8=SCL`、`PB9=SDA`，地址 `0x3C`。
- MaixCAM2：`A21/UART4_TX -> PA10/USART1_RX`，115200 8N1，
  二进制协议版本 2，带 CRC16-CCITT。
- TIM3 产生非阻塞 STEP，TIM2 每 1 ms 做速度/加速度规划。
- 开环命令位置软限位为 `±100 STEP`，上电机械中心作为软件零点。
- K3 使能/失能，K1/K2 每次把目标位置增加/减少 20 STEP。

本基线尚未启用钢球 PID。OLED 的 `P/T/V/EN` 分别表示命令脉冲位置、
目标脉冲位置、当前请求速度和驱动使能状态。

## 目录

- `stm32f103c8t6/`：Keil MDK-ARM 工程和 STM32 标准外设库源码。
- `maixcam2/main.py`：MaixCAM2 视觉检测、五点标定和 UART 发送程序。

## 安全说明

系统没有机械原点或限位开关，命令位置不等于编码器反馈。每次上电必须先
将水管放在机械中心；改变软限位、最大速度或加速度前需确认机械行程安全。
