# V27 版本说明

本版先完成起步、弯道确认、OLED 刷新和速度衔接优化。陀螺仪角速度或赛道里程参与弯道判断的功能暂未加入，等待实测数据后再做。

## 1. PB22/PB23 起步更平缓

- PB22、PB23 的加速步长由每 10 ms 增加 2‰ 改为增加 1‰。
- PB22 从 0 加到最大速度 363‰，理论时间约 3.63 s。
- PB23 从 0 加到最大速度 266‰，理论时间约 2.66 s。
- PA18 的起步参数没有修改。
- PB22、PB23 的减速步长仍为每 10 ms 降低 3‰。

实际到达最大速度时所处的赛道位置与电池电压、负载和电机状态有关，需要上车确认是否已经达到“直线段大半”的目标。

## 2. 延长弯道连续确认时间

- 弯道进入条件需要连续成立 80 ms，原来为 30 ms。
- 短暂的循迹误差或单次灰度跳变不会立即把车辆切换到弯道状态。

## 3. OLED 分片、非阻塞刷新

- OLED 初始化、清屏、标签和时间显示全部改为分阶段状态机。
- 每次 1 ms 任务调用最多启动一笔 8 字节 I2C 传输，启动后立即返回。
- 不再使用阻塞循环等待整屏刷新完成，避免 OLED 刷新占用循迹控制时间。
- OLED 未连接或通信错误时进入失败状态，不阻塞电机控制。
- OLED 接线仍为 PA0/SDA、PA1/SCL。

## 4. 确认弯道后才切换弯道速度

- 处于疑似弯道但尚未连续确认的阶段时，仍保持当前直线速度目标。
- 只有弯道状态确认后，才把目标速度切换到对应按键模式的弯道速度。

## 5. 直线与弯道速度平滑衔接

- 确认进入弯道后，速度限制按照减速步长逐渐过渡到弯道速度，不会瞬间跳变。
- 离开弯道后，中间探头稳定居中 150 ms 才确认进入直线。
- 确认直线后，再按照加速步长逐渐恢复直线速度。
- PA18、PB22、PB23 保持各自独立的最大速度、弯道速度和循迹参数。
