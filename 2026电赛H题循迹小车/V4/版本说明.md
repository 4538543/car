# V4：PA18抖动修复与终点漏检修复

生成日期：2026-07-30

## 实车现象与原因

### PA18直线剧烈抖动

- PA18和PB22使用同一套灰度PID，但PA18开启了左右编码器累计等距离纠偏，PB22关闭了该功能。
- 实车表现为PA18抖动而PB22直线平顺，说明累计编码器位置环在反复抵消灰度PID的方向修正。
- V4让PA18与PB22使用相同的方向控制结构：灰度PID负责方向，编码器不再干预左右轮累计距离差。
- 编码器仍正常用于实时速度、任务里程、减速停车和堵转检测。

### 一圈驶过终点很远才停车

- V3漏检保护为约6700mm，而赛道理论一圈为6142mm。
- 两者相差约558mm，与实车“经过终点后走到下一段直线中间才停”吻合。
- 这说明当时没有进入`LINE HIT`状态，最终触发的是漏检保护。

## 终点识别改动

- 终点横线最少黑色探头数从4个放宽到3个。
- 最少连续黑色探头数从4个放宽到3个。
- 仍要求最多只能有6个黑色探头，因此DAT断线造成的8灯全黑不会触发。
- 取消“必须包含正中两个探头”的要求。小车从最后一个圆弧进入终点时即使仍有横向偏差，也可以识别横线。
- 仍需连续确认20ms，抑制单帧噪声。

典型判定结果：

| 灰度状态 | 是否为终点 |
|---|---|
| 普通轨迹1～2灯 | 否 |
| 任意位置连续3～6灯 | 是 |
| 3灯但不连续 | 否 |
| 8灯全黑 | 否 |

## 漏检保护

```c
/* V3：约6700mm，理论终点后约558mm */
#define LAP_MISSED_MARKER_STOP_COUNT (47756U)

/* V4：约6322mm，理论终点后约180mm */
#define LAP_MISSED_MARKER_STOP_COUNT (45068U)
```

正常识别横线后仍按以下流程停车：

`LINE HIT → 继续循迹约130mm → 减速 → 最迟横线后约180mm制动`

如果横线再次漏检，车辆也不会继续驶入下一段直线中部，而是在理论终点后约180mm进入`FAULT`安全停车。

## 实车复测观察

1. PA18启动后直线应接近PB22直线段的平顺程度。
2. 一圈返回A点时观察LCD：
   - 出现`LINE HIT`表示终点横线识别成功；
   - 出现`FAULT`表示横线仍被漏检，停车来自编码器保护。
3. 若仍漏检，请记录经过横线瞬间亮起的灰度灯数量和位置，再据此调整规则，不要继续盲目增加越线距离。
