# V16 版本说明

日期：2026-08-01

## 本版目的

修改 PA18 一圈停车条件：距离、灰度、陀螺仪角度三个条件同时满足才停车。

## 本版改动

- 一圈停车距离阈值改为约 3600 mm：
  - `LAP_DISTANCE_STOP_COUNT = 25650`
- 新增一圈停车角度阈值：
  - `LAP_DISTANCE_STOP_MIN_ANGLE_CENTIDEG = 33000`
  - 对应 `+330.00 deg`
- PA18 一圈立即停车模式现在要求同时满足：
  - `lapCount >= LAP_DISTANCE_STOP_COUNT`
  - `GraySensor_getActiveCount() == 3`
  - `Gyro_getIntegratedAngleCentiDeg() >= 33000`
