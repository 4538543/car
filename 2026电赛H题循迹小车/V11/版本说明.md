# V11 版本说明（回滚到 V8）

## 本版性质

V11 是一次可追溯的回滚记录：活动工程的源码、头文件、`empty.syscfg`、CCS 工程配置和配套说明均恢复为 V8 的内容。

Git 历史中的 V9、V10 没有删除或改写，需要时仍可查看和恢复。

## 恢复后的功能基线

- 使用 V8 的巡线、任务状态机、启停线识别和停车逻辑。
- 恢复 V8 针对圆弧出口的最外侧双探头启停线识别。
- 恢复 V8 的持续圆弧差速辅助，用于减少圆弧段切线式、多边形式行驶。
- 保留 V8 已有的 LCD、编码器、陀螺仪和 STM32 串口通信功能。

## 不再包含的后续修改

- 不包含 V9 新增的确定性一圈停车修复、扩展双灯掩码及陀螺仪累计转角兜底。
- 不包含 V10 的更缓起停、更小反向制动力和更高直线最大速度参数。

## 构建验证

- 已使用 CCS 21 配套 SysConfig 1.28.0 重新生成配置文件。
- 已执行 Clean Build，所有模块编译并链接成功。
- 可烧录固件：`firmware/car_H_V11.out`。
