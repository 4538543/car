# 2026 电赛 H 题循迹小车

这是独立于仓库中原有小车工程的新项目，版本号从 `V1` 重新开始。

每次形成一版可用代码后，新建一个连续版本目录：

- `V1`：本项目首版。
- `V2`：增强圆弧贴线能力，加入终点横线识别和越线后车身覆盖停车。
- `V3`：LCD增加实时速度，修复单中间灯起步猛偏并抑制直线摇摆。
- `V4`：消除PA18编码器环抖动，修复一圈终点横线漏检和过度越线。
- `V5`：中心容许区改为仅起步有效，修复正常行驶时车身长期横向偏置。
- `V6`：适配探头位于启停线后方的新起点，重映射三种任务，并加入整车通过A/B后的分阶段计时和停车。
- `V7`：放宽并提前启停线识别，新增向STM32发送角速度、角加速度、纵向加速度和运动阶段事件。
- `V8`、`V9`……：后续版本，不覆盖旧版本。

每个版本目录保存完整 CCS 工程源码、SysConfig 配置、版本说明和可烧录固件。
