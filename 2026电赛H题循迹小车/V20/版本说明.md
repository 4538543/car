# V20 版本说明

本版在 V19 基础上再次提速，并把正常运行期间的所有速度变化统一改为平滑斜坡。

## 再次提速

- PA18：巡航 PWM `286 -> 372`，接近终点阶段 `221 -> 287`，相对 V19 再提高约 30%。循迹 PID、最大转向修正、弯道前馈和弯道速度能力由 V8 基准的 130% 提高到 169%，即相对 V19 再提高 30%。
- PB22：巡航 PWM `330 -> 363`，接近阶段 `198 -> 218`，通过 B 点后 `176 -> 194`，相对 V19 再提高约 10%。
- PB23：巡航 PWM `242 -> 266`，接近阶段 `187 -> 206`，通过 A 点后 `176 -> 194`，相对 V19 再提高约 10%。
- PB22/PB23 循迹能力由 V8 基准的 110% 提高到 121%，即相对 V19 再提高 10%。

## 全过程平滑变速

- PA18 每 10 ms 加速 4 PWM、减速 5 PWM。
- PB22/PB23 每 10 ms 加速 2 PWM、减速 3 PWM，进一步减小加速度。
- 起步从 0 逐步升至目标速度。
- 灰度误差连续达到弯道条件 30 ms 后确认进入弯道，再按减速斜坡逐步降低速度，不再直接截断 PWM。
- 灰度重新回到中心区域并连续保持 150 ms 后确认进入直线，再按加速斜坡逐步恢复直线速度。
- 任务内部的巡航、接近、通过目标点以及最后停车全部使用相同的斜坡机制。
- PA18 检测到终点线后不再直接停止电机，而是把目标速度设为 0，平滑减速到 0 后再执行短时反向制动。
- PB24 为紧急停车，仍立即关闭电机输出，不经过斜坡。
