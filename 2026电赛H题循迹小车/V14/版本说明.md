# V14 版本说明

日期：2026-08-01

## 本版目的

修改 PA18 一圈停车逻辑：小车行驶距离大于 3500 mm，并且至少 4 个灰度传感器扫到黑线时停车。

## 本版改动

- `LAP_DISTANCE_STOP_COUNT` 改为 `24937`，对应约 3500 mm。
- PA18 一圈立即停车模式不再单独按距离停车，而是同时满足：
  - `lapCount >= LAP_DISTANCE_STOP_COUNT`
  - `GraySensor_getActiveCount() >= 4`
- PB23 的“识别 A 点后整车通过再停”逻辑未修改。

## 关键位置

- 距离大于 3500 mm 的阈值：`app_config.h` 中 `LAP_DISTANCE_STOP_COUNT`
- 停车组合判断：`ab_mission.c` 中 `lapCount >= LAP_DISTANCE_STOP_COUNT` 与 `GraySensor_getActiveCount() >= 4U`

## 验证

- CCS/SysConfig clean build 通过。
- 烧录文件：`firmware/car_H_V14.out`
